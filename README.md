## ✨ Features

- 🎉 Pre-plan events in a few clicks
- 🍛 Browse and choose catering options
- 📅 Manage bookings and orders
- 📱 Simple, clean interface

## 🚀 How to Run

1. Download or clone this repository
2. Open `cat9.html` in any web browser
3. Start planning your event!
